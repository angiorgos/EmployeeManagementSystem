# Employee Management System

Ένα ολοκληρωμένο σύστημα διαχείρισης ανθρώπινου δυναμικού (HR) και υπαλλήλων, γραμμένο σε **Java** με χρήση του **Spring Boot** για το backend και του **JavaFX** για το γραφικό περιβάλλον (GUI).

## Τι είναι αυτό το project
Το Employee Management System είναι μια Desktop εφαρμογή που επιτρέπει στις επιχειρήσεις να διαχειρίζονται εύκολα το προσωπικό τους. Κάποιες από τις βασικές του λειτουργίες περιλαμβάνουν:
- **Διαχείριση Υπαλλήλων (Employees) & Τμημάτων (Departments)**
- **Παρακολούθηση Παρουσιών (Attendance)**
- **Διαχείριση Αδειών (Leaves) & Αιτημάτων Άδειας**
- **Διαχείριση Αργιών (Holidays)**
- **Μισθοδοσία (Payroll)**
- **Προγραμματισμός Βαρδιών / Ωραρίων (Schedule)**
- **Καταγραφή Συμβάντων (System Logs / Audit)**

Η εφαρμογή χρησιμοποιεί **PostgreSQL** για βάση δεδομένων και κάνει χρήση του Spring Data JPA.

## Δομή του Project

Το έργο ακολουθεί μια κλασική αρχιτεκτονική διαχωρισμού σε επίπεδα (layered architecture), συνδυάζοντας το Spring Boot με το JavaFX MVC pattern. Ο βασικός κώδικας βρίσκεται στον φάκελο `src/main/java/org/project/employeemanagementsystem/`:

- **`model/`**: Περιέχει τις κλάσεις που αναπαριστούν τις οντότητες της βάσης δεδομένων (π.χ. `Employee`, `Department`, `Attendance`, κ.α.). Χρησιμοποιεί JPA Annotations και Lombok.
- **`repository/`**: Interfaces που κληρονομούν από το `JpaRepository` του Spring Data JPA, υπεύθυνα για την επικοινωνία με την PostgreSQL (CRUD λειτουργίες).
- **`service/`**: Η επιχειρησιακή λογική (Business Logic) της εφαρμογής. Λειτουργεί ως ενδιάμεσο επίπεδο μεταξύ των Controllers και των Repositories.
- **`controller/`**: Περιέχει τους JavaFX Controllers που συνδέονται απευθείας με τα αρχεία `.fxml` (UI). Διαχειρίζονται τις ενέργειες του χρήστη (κλικ, φόρμες) και επικοινωνούν με τα `services`.
- **`config/`**: Κλάσεις ρυθμίσεων. Για παράδειγμα το `DataSeeder` που εισάγει αυτόματα τα αρχικά δεδομένα.
- **`util/`**: Βοηθητικές κλάσεις όπως το `Navigator` για την εναλλαγή οθονών στο JavaFX και το `UserSession` για τη διατήρηση της κατάστασης του συνδεδεμένου χρήστη.

### Πόροι (Resources)
Στον φάκελο `src/main/resources/` θα βρείτε:
- **`fxml/`**: Εδώ βρίσκονται τα αρχεία σχεδιασμού του γραφικού περιβάλλοντος (π.χ. `dashboard.fxml`, `employees.fxml`).
- **`charts/`**: HTML/JS αρχεία για την προβολή γραφημάτων (μέσω JavaFX WebEngine/WebView).
- **`application.properties`**: Το βασικό αρχείο ρυθμίσεων της εφαρμογής (εκεί ορίζεται η σύνδεση με τη βάση δεδομένων).
- **CSS αρχεία**: Χρησιμοποιούνται για την αισθητική διαμόρφωση (styling) της εφαρμογής (π.χ. `theme.css`).

## Οδηγίες Εκτέλεσης

Για να δουλέψει η εφαρμογή, πρέπει να βάλετε στο `src/main/resources/application.properties` τα στοιχεία της PostgreSQL βάσης σας (username, password, database url).

Αν τρέξετε την εφαρμογή για πρώτη φορά, **θα δημιουργηθούν αυτόματα ενδεικτικά δεδομένα** στη βάση δεδομένων (χάρη στο `DataSeeder`), ώστε να μπορείτε να δοκιμάσετε άμεσα τις λειτουργίες της.
